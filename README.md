# Project-Notetracker

Grade Manager

A simple command-line application to manage and track grades for different subjects.

Features
- Add subjects
- Remove subjects
- Add grades to subjects
- View grades with the averages
-  data storage in a text file


Usage
1. Add Subject: Add a new subject to track grades.
2. Remove Subject: Remove an existing subject.
3. Add Grade: Add a grade to a specific subject.
4. View Grades: View all subjects, their grades, and the average grade for each subject.
5. Exit: Close the application.

File Structure
- `grade_manager.py`: The main script for the Grade Manager application.
- `subjects.txt`: The file where subjects and grades are stored.

How It Works
- The application loads existing subjects and grades from `subjects.txt` when started.
- All changes (adding/removing subjects, adding grades) are saved to `subjects.txt`.
- The application provides a simple menu-driven interface for user interaction.
